# ENG Drawing Viewer website

Static Astro product website for https://ca-works.github.io/eng-drw/.

Use Node 24 LTS. Install with `npm ci`, preview with `npm run dev`, verify with `npm run check && npm run build`. Browser tests: `npx playwright install chromium firefox webkit` then `npm test`.

The app is a separate project. No application source, private history, installers or audit records belong here. Downloads are driven by verified release metadata; unreleased platforms display Coming soon. See docs/RELEASING.md.
